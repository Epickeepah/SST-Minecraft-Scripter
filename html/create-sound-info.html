Creating Addon

Manifest

Now we get to the fun part. The manifest is very simple for this addon in particular all you need to do is put in the name of your addon. Exp: "Greatest Sound Addon". Then your discription (Discription not Required). Your discription can be anything you want it does not matter its just simply there to tell you a little bit about that Addon. Then make sure you click create manifest before moving on to the next part. As of right now you have to click create manifest for the addon creation to work, it is a bug that will get fixed later.



sounds.json/sound_definition.json

This part is probably the easiest part all you do is either pull in your sound files into the black box or click "Import Audio" then it does the rest. There is no limit on how many files you can add. One thing to note though is if you try to pull a file in that is not in .ogg format it will not work becuase that is the only format minecraft can read.



Downloading

We have two download options. 1. "Create Sound" this option lets you place the addon wherever you want it through your file explorer. 2. "Download as mcaddon" this lets you download the file as a zip and makes it so you can just click "open file" or double click the file and it will open minecraft for you and download the addon straight to minecraft. This is what I recomend for newcomers.



In Game

Once you have downloaded the pack into minecraft you want to add the pack as a resource in your world settings. Once that is done and you get in game you want to run this command "/playsound random.(Your sound name)" if you have a space in your sound name the command changes and looks like this "/playsound "random.(Your sound name)" ". I will show some examples now. First example will show if you do NOT have any spaces in your sound name. Exp1: /playsound random.hello. Example two will show if you do have spaces in your sound name. Exp2: /playsound "random.hello world". If you need any further help feel free to send me a message through Discord or Email.
